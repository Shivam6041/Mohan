# ESP32 AI Server Communication

This project demonstrates how an ESP32 can communicate with a server and display messages typed on a web page.

## Features
- Web page to input text
- ESP32 fetches and displays text
- AI-ready architecture
- Beginner friendly

## Requirements
- ESP32
- Python 3
- Flask
- Arduino IDE

## How to Run Server
```bash
pip install flask
python server.py
